✅ Passo a passo o procedimento indicado abre destacado
Programação Programar férias — >CAIFFERIAS (tela preta)

Use quando ainda não há férias cadastradas para o exercício. Também é o caminho da vacância TAE → docente (45 dias no ano da vacância).

  1. COMANDO: >CAIFFERIAS → Enter.
  2. Identifique o servidor → marque X no resultado → Enter.
  3. Mais de uma matrícula? Escolha a que não tenha info em [OCORR. EXC].
  4. ANO DE EXERCÍCIO DAS FÉRIAS → Enter. Se aparecer “JÁ EXISTEM FÉRIAS...”, pare: o caminho é Alteração.
  5. QTDE PARCELAS conforme o requerimento.
  6. PERÍODO AQUISITIVO: não alterar → Enter.
  7. DATA INÍCIO / QTDE DE DIAS BRUTO da parcela.
  8. ADIANT. GRAT. NATALINA (S/N — só “S” se a parcela iniciar entre jan e maio).
  9. ADIANT. SALARIAL (S/N) e MESES DESCONTO: 1 se salarial = S; deixe vazio se = N → Enter. Repita 7–9 por parcela.
  10. CONFIRMA FÉRIAS? S → NOTIFICAÇÃO? N → Enter.
Parcela iniciando no ano seguinte = acúmulo: preencha a justificativa (“Acúmulo devido ao serviço e autorizado pela chefia imediata”) e S em “DESEJA CONTINUAR”.
Alteração Alterar férias — CAPRFERIAS (e-Siape)

Use quando as férias já existem e a parcela a mudar inicia em folha futura (ou no mês da folha em aberto, sem mudar dias).

  1. Lupa → digite CAPRFERIAS → Enter.
  2. Identifique o servidor → clique no nome. Mais de uma matrícula? A sem info em [OCORR. EXC AFAS].
  3. Selecione o Exercício.
    “EXISTE SOLICITAÇÃO EM ABERTO NA WEB” → [ENTER] CONTINUAR (isso invalida o pedido feito pelo servidor na web).
    “ESTAS FÉRIAS JÁ ESTÃO QUITADAS...” → [ENTER] CONTINUAR, mas vira histórica: exige também o lançamento no SUAP.
  4. Quantidade de parcelas → Enter.
  5. Data início (avance até a parcela certa — ex.: a 3ª) e Qtd de dias brutos.
    Obs.1: se a parcela inicia dentro do mês da folha em aberto, o sistema só aceita nova data no mesmo mês e não deixa mudar a qtd de dias → use Cancelamento.
    Obs.2: se inicia em folha anterior, só permite em data futura (correção histórica) → use Alteração Histórica.
  6. Adiant. grat. natalina (S/N), Adiant. salarial (S/N), Meses desconto (1 se S; vazio se N). Repita por parcela.
  7. CONFIRMA REPROGRAMAÇÃO? Sim → NOTIFICAÇÃO? Não.
Cancelamento Cancelar parcela — >CACAFERIAS (tela preta)

Use quando a parcela inicia no mês da folha em aberto e você precisa mudar a qtd de dias ou jogar para uma folha futura. Depois traga de volta pelo CAPRFERIAS.

  1. >CACAFERIAS → Enter → identifique → X → Enter (matrícula sem [OCORR. EXC AFAS]).
  2. Confira PERÍODO DE FÉRIAS DA PARCELA (parcela correta).
  3. DATA INÍCIO PROGRAMADA P/ GOZO DA PARCELA CANCELADA: o sistema não aceita data no mês/folha atual → ponha uma data qualquer em folha próxima (depois corrige via CAPRFERIAS).
  4. F2 para iniciar o DL (Documento Legal). No requerimento localize nº e sigla do setor.
  5. UORG: F1 em SIGLA A PARTIR DE → sigla → Enter → X → Enter.
  6. ANO e NÚMERO do requerimento · TIPO = 8 · ASSUNTO = 232.
  7. EMISSÃO / VIGÊNCIA / PUBLICAÇÃO: 1 dia antes da data atual OU 1 dia antes do início da parcela cancelada — a mais antiga das duas.
  8. F4 → CONFIRMA INCLUSÃO? S → Enter → CONFIRMAR CANCELAMENTO? S → Enter → NOTIFICAÇÃO? Não.
Erros (4825) DATA MENOR QUE CORRENTE ou DATA GOZO > ANO/MÊS PGTO → use data em folha próxima. Se não conseguir reajustar depois, desfaça em >CAANCANFER.
Rode FPCLPAGO: se houve desconto de férias, avise o servidor. Se o desconto negativar a folha, comunique com urgência a DACP-DGP: dacp.prd@ifsp.edu.br.
Histórica Alteração histórica / continuação de interrupção — SUAP + Siape

Use quando CAPRFERIAS/CACAFERIAS não liberam (parcela em folha anterior, férias já quitadas, ou interrupção). O sistema só libera a alteração no Siape 2 folhas após o último evento (fim das férias agendadas ou nova data final).

Agora, no SUAP (o extrator não traz alteração histórica nem interrupção):

  1. SUAP → Gestão de Pessoas → Administração de Pessoal → Férias → Listagem de Férias.
  2. Filtrar: Texto = nome · ano = exercício · Campus = Todos · Subsetores = Todos → Filtrar.
  3. Abra em editar. Preencha os períodos corretos (como as férias serão usufruídas).
  4. Desmarque a caixa Atualizar pelo Extrator?
  5. Preencha as parcelas de continuação de interrupção, se houver → Salvar.

Depois, no Siape: aguarde a data futura (2 folhas após o último evento) e faça a alteração via CAPRFERIAS.

Adicional Lançar 1/3 manual — >FPATMOVFIN

O adicional é devido só no 1º período, independentemente dos dias. Em cadastro intempestivo o sistema pode não pagar automático → confira em >FPCLPAGTO.

  1. >FPATMOVFIN → identifique o servidor.
  2. Rubrica 00220 · Operação I - INCLUSÃO · Parametrizada.
  3. MÊS/ANO REF = mês do 1º período · Valor = adicional calculado abaixo.
  4. Assunto de cálculo 44 · Doc. legal LEI 8112 · justificativa (ex.: “1/3 de férias referente ao 1º período do exercício... marcação intempestiva/histórica”).
Rubrica: 00220 (efetivos) · 00750 (contratados). 1º período em ano anterior → processo de exercício anterior, objeto 0069.
Calculadora do adicional
Divisor: 3 (1/3 — 30 dias)
R$ 0,00
Docente = ÷ 2 (1/2); Adm./contratado = ÷ 3 (1/3). Some as rubricas que compõem a remuneração.
